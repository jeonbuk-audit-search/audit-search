# 큰그릇실장 조회수 LIVE · 모바일 웹앱

공개 웹주소: https://jeonbuk-audit-search.github.io/audit-search/

## 설치
- Android Chrome: 웹주소 열기 → '앱 설치' 또는 브라우저 메뉴(⋮) → '홈 화면에 추가' / '앱 설치'
- Samsung Internet: 메뉴 → '현재 페이지 추가' → '홈 화면'
- 데스크톱 Chrome / Edge: 주소창의 설치 아이콘 또는 브라우저 메뉴의 '앱 설치'

## 기능
- 교육청 게시판에 게시된 5개 프로그램(학교회계, 감사ON, 계약실무, 늙크크 AI 공작소, 법령ON) 조회수를 공개 GitHub 수집 이력에서 확인
- 법령ON 등록 이전의 4개 합계는 별도 집계 기준으로 표시하며 5개 합계와 직접 비교하지 않음
- 합계, 이전 확인 대비 변화, 최근 조회 시각과 수집 지연 경고
- 30분 단위 표시, 미수집 시간대 '기록 없음' 처리
- CSV 및 JSON 이력 다운로드
- 홈 화면 아이콘, 전체 화면에 가까운 PWA 실행, 앱 화면 오프라인 캐시

## 중요
- 30분은 목표 간격입니다. GitHub Actions 예약 작업은 지연·누락될 수 있습니다.
- 앱을 열거나 '저장 기록 불러오기'를 누르는 것만으로 교육청 사이트를 새로 수집하지 않습니다.
- 앱의 과거 기록은 인터넷 연결 시 확인한 공개 목록의 수집 시각 기준입니다.
- 오프라인 상태에서는 앱 화면만 열릴 수 있고, 최신 데이터를 제공하지 않습니다.
- 상세 페이지를 새로 조회하지 않고 게시판 목록에서 조회수를 수집하므로 조회수 증가를 유발하지 않도록 구성했습니다.
