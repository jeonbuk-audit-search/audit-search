# 학교 업무 인수인계 프로그램 기획서 (초안)

> 대상: 전북특별자치도교육청 소속 학교 행정실·교무실 담당자
> 기존 「감사사례 검색기」와 연계하여 "인수인계 + 감사 사전예방"을 한 화면에서 해결

## 1. 목적과 문제 정의
| 문제 | 해결 방향 |
|---|---|
| 3·9월 정기인사 때 담당자가 바뀌면 업무 맥락이 끊김 | 업무를 **주기(일·월·분기·년)별 카드**로 쪼개 표준화 |
| 인수인계서가 담당자마다 제각각, 파일로만 존재 | 공통 양식 + 시스템 저장, 후임자는 "오늘 할 일"부터 확인 |
| 놓친 기한(계약·정산·보고)이 감사 지적으로 이어짐 | 업무 카드에 **관련 감사 지적사례 자동 연결** |

## 2. 핵심 개념
- **업무 카드**: 업무명 / 주기 / 기한 / 담당 역할 / 근거 법령·지침 / 처리 절차 / 사용 시스템(나이스, 에듀파인, K-에듀파인, e-호조 등) / 유의사항 / 관련 감사사례 / 증빙 위치
- **역할(Role) 기준 인계**: 사람이 아니라 직위(예: 행정실장, 시설담당, 회계담당, 교무기획)에 카드를 귀속 → 인사이동 시 역할 전체를 후임에게 일괄 이관
- **진행 상태**: 미착수 / 진행 / 완료 / 해당없음(사유) + 완료일·증빙 메모

## 3. 주기별 기획

### 3-1. 일별 (Daily) — "오늘 할 일" 화면
| 구분 | 항목 예시 |
|---|---|
| 회계 | 수입·지출 결의 처리, 지출 증빙 확인, 세금계산서·카드 결제 내역 확인 |
| 계약 | 수의계약 견적서 접수·비교, 계약 체결 전 요건 점검 |
| 복무 | 출장·연가·초과근무 결재 확인(여비·초과근무 지적 빈출) |
| 시설 | 시설 점검 일지, 급식·안전 일일 점검 |
| 문서 | 공문 접수·배부, 미처리 문서 확인 |
**기능**: 당일 체크리스트 / 전일 미완료 이월 / 오늘 처리해야 할 마감(D-day) 상단 노출 / 업무 카드 클릭 시 절차·감사사례 팝업

### 3-2. 월별 (Monthly)
| 월 구분 | 항목 예시 |
|---|---|
| 매월 공통 | 급여·수당 지급 확인, 4대보험·원천세 신고납부, 월 결산, 통장·예금 잔액 대사, 시간외·여비 정산, 비품·재물 취득 등록, 학교운영비 집행률 점검, 급식비 정산 |
| 월별 특수 | **3월** 학교회계 예산 편성·교직원 인사 후 인계, 학교운영위원회 / **5~6월** 수학여행·현장체험학습 계약 / **7~8월** 방학 중 시설공사·방학 중 근무 / **9월** 2학기 인사 인계 / **11~12월** 예산 불용·이월 정리 |
**기능**: 월 달력 보기 / 월말 마감 체크 / 월간 진행률 리포트(PDF·엑셀)

### 3-3. 분기별 (Quarterly)
| 분기 | 항목 예시 |
|---|---|
| 1분기(1~3월) | 신학년 업무분장, 학교회계 본예산 확정, 정보공시 준비, 인수인계서 작성·검수(2월 말) |
| 2분기(4~6월) | 1분기 집행 실적 점검, 현장체험·수학여행 정산, 정보공시(4월), 안전·소방 점검 |
| 3분기(7~9월) | 반기 결산, 추경 편성, 하반기 계약 계획, 2학기 인수인계(8월 말) |
| 4분기(10~12월) | 예산 집행 최종 점검, 불용액·이월 정리, 자체감사 점검, 재물조사 계획 |
**기능**: 분기 점검표(자체점검 체크리스트) / 분기별 감사 지적 빈출 TOP 안내 / 미이행 업무 자동 경고

### 3-4. 연간 (Yearly)
| 시기 | 항목 예시 |
|---|---|
| 1~2월 | 학교회계 결산, 연말정산, 인사발령 대비 **인수인계서 확정**, 신학년도 계획 |
| 3월 | 신규 담당자 **인수 확인(인계·인수 서명)**, 학교회계 예산 편성, 각종 위원회 구성 |
| 4~6월 | 학교 정보공시, 건강검진·안전 점검, 교육청 정기·종합감사 대비 |
| 7~8월 | 방학 중 시설 보수, 2학기 준비, 하반기 인사 인계 |
| 9~10월 | 추경, 재물조사, 각종 계약 이행 점검 |
| 11~12월 | 결산 준비, 불용·이월, 연말 정산, 차년도 업무 계획 |
**기능**: 연간 업무 캘린더 / 전년도 대비 변경점 비교 / 연간 인수인계서 자동 생성(해당 역할의 모든 카드 합본)

## 4. 인사이동 인수인계 플로우
1. **인계 준비(D-30)**: 전임자가 역할 카드 최신화 + 진행 중 업무·미결 사항 입력
2. **인계서 생성(D-14)**: 주기별 카드·진행 현황·증빙 위치 자동 합본(PDF)
3. **인수 확인(D-0)**: 후임자 열람·질의, 전·후임 전자서명
4. **사후 지원(D+30)**: 첫 달 "이번 달 꼭 할 일" 알림, 전임자에게 질의 메모 남기기
5. **관리자 확인**: 학교장·행정실장이 인계 완료율 확인

## 5. 감사사례 연계 (기존 앱 활용)
- 업무 카드 키워드(수의계약, 여비, 초과근무, 수학여행 등)로 `감사결과_통합DB`를 자동 검색해 "이 업무에서 자주 지적된 사례" 표시
- 월·분기 점검표에 해당 시기 지적 빈출 항목을 자동 삽입

## 6. 화면 구성
1. **홈**: 오늘 할 일 / 이번 주 마감 / 이번 달 진행률
2. **주기별 보기**: 일 · 월 · 분기 · 연 탭
3. **업무 카드 상세**: 절차·근거·감사사례·증빙·메모
4. **인수인계**: 인계서 작성·생성·서명
5. **관리자**: 학교별 인계 현황, 카드 템플릿 관리

## 7. 데이터 구조(안)
`역할(role)` ─1:N─ `업무카드(task)` ─1:N─ `수행기록(log: 날짜, 상태, 메모, 증빙)`
`task`: id, role, 업무명, 주기(일/월/분기/년), 기한규칙(매월 말일, 3월 첫 주 등), 근거, 절차, 키워드, 사용시스템
`handover`: id, 학교, 역할, 전임, 후임, 상태, 서명일

## 8. 개발 로드맵
| 단계 | 내용 | 기술 |
|---|---|---|
| 1단계(MVP, 2~3주) | 업무 카드 + 주기별 목록 + 체크리스트, 감사사례 연동 | Streamlit + CSV/엑셀 (기존 앱 구조) |
| 2단계(3~4주) | 인계서 PDF 생성, 인수 확인, 학교별 로그인 | Streamlit + SQLite, 인증 |
| 3단계 | 알림(마감 D-day), 교육청 관리자 대시보드, 템플릿 배포 | DB 서버, 공문·메신저 연계 검토 |

## 9. 확정이 필요한 사항
1. 대상: 행정실만 / 교무실 포함 / 전체 학교 공통 템플릿?
2. 이용 환경: 교육청 내부망 vs 외부(개인정보·보안 검토 필요)
3. 초기 업무 카드 작성 주체: 감사관실 표준안 vs 학교별 자율 작성
4. 에듀파인·나이스 등 기존 시스템 연계 여부(대부분 수동 입력으로 시작 권장)
5. 개인정보·공문서 보안 기준(인계서에 민감정보 입력 금지 안내)
